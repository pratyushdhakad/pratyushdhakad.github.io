# Pratyush Dhakad — personal website

A single-page portfolio for Pratyush Dhakad, built as a static GitHub Pages site. It introduces his BI and applied AI work, links to four reproducible public projects, and includes career and personal context.

## Local preview

Run `python3 -m http.server 8765` here and open `http://localhost:8765/`.

## Implementation

Plain HTML, CSS, and JavaScript. `styles.css` contains the original site styles; `refinement.css` adds the 2026 chapter navigation, responsive refinements, and interaction polish. Scroll motion is lightweight and respects `prefers-reduced-motion`. No build step or analytics tracker is required. See `DESIGN_SYSTEM_2026-10-28.md` for the applied UI/UX rules and source.

## Content sources

Career facts were checked against Pratyush's career canon, current LinkedIn profile, GitHub repositories, and his workspace instructions in October 2026. The portrait is from his local headshots folder.
